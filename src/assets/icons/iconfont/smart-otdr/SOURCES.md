# 智能 OTDR 图标来源与配色

核对日期：2026-10-10。来源：[阿里巴巴 iconfont](https://www.iconfont.cn/)。本轮使用其公开搜索 `POST /api/icon/search.json` 检索并视觉核对；未重新检索的通用图标沿用上级 device/SOURCES.md 中已记录的阿里来源。

SVG 路径与 viewBox 保留，统一填色与显示尺寸，资源随项目本地打包。原作者保留权利。图标 ID 与图标库搜索可追溯；不是重新绘制后冒称阿里图标。

蓝色用于测量、导航与常规操作；青绿用于功率和连接；紫色用于检测分析；琥珀用于照明和文件夹；红色用于激光、危险操作和 PDF 文件。开启／关闭仍有文字与状态样式，颜色不独自承担状态含义。

事件地图中的硬件事件符号、A/B 测量标记与曲线数据不属于通用功能图标，保留既定硬件语义。
