二、产品与服务内容

当前版本根据客户端类型、账号权限、设备型号和网络条件，可能提供以下全部或部分功能：

  • 通过手机号、邮箱、验证码或密码进行注册和登录；微信小程序通过微信登录及手机号授权完成快捷登录；
  • 查看和修改昵称、邮箱等账号资料，退出登录或注销账号；
  • 浏览产品分类、产品资料、关于信息和操作手册；
  • 扫描、连接、绑定、解绑和管理兼容的蓝牙设备；
  • 扫描设备二维码，通过4G通道连接设备并下发控制指令；
  • 进行设备激活、授权期限设置、设备启动密码设置、固件检查和更新；
  • 操作光功率计（OPM）、红光源（VFL）、OTDR、熔接机及其他兼容设备，查看、保存、删除或导出相应记录；
  • 提交和查询售后订单、物流信息及处理结果；
  • 切换界面或设备语言，并使用微信平台提供的分享能力。

不同平台的功能可能不同。例如，APP可提供手机号/邮箱注册登录；微信小程序通过微信临时登录凭证和手机号授权登录，服务器会根据授权手机号识别、创建或关联账号，具体以服务器校验结果为准。拒绝手机号授权时，当前微信小程序没有其他登录方式。相机、蓝牙、相册和文件能力也受操作系统或微信平台限制。页面显示、设备实际能力和服务器返回结果为准。

当前版本未提供面向用户的支付、广告投放、公开内容发布或社交关系功能。后续如新增相关功能，我们将依法更新规则并在必要时另行取得您的同意。

三、账号注册、登录与安全

1. 您应提供真实、准确、合法、有效的手机号或邮箱等注册信息，并及时维护可用的联系方式。微信小程序快捷登录需要您主动同意微信手机号授权。

2. 您应妥善保管账号、密码、验证码、登录设备和其他身份凭证，不得出租、出借、转让、售卖账号或允许他人以您的身份实施违法违规行为。

3. 如发现账号被盗用、异常登录或其他安全风险，请立即停止相关操作并通过本协议列明的方式联系我们。因您主动泄露、保管不善或违反本协议造成的损失，由责任方依法承担。

4. 退出登录仅会清除当前设备上的登录状态，不等于注销账号，也不会自动删除服务器中的账号和业务记录。

5. 您可在设置页选择“注销账号”并按页面提示完成确认。账号注销后无法恢复。我们将匿名化账号资料，解除微信和设备绑定，并删除不再需要的数据；法律法规要求保留的售后、安全审计等业务记录除外。如自助注销遇到问题，您仍可通过本协议列明的联系方式提交申请。设备本地缓存可通过系统清除应用数据、删除小程序或卸载应用清除。

6. 设置页当前支持修改昵称和邮箱。手机号或其他资料的查询、更正、复制和删除，可通过《光纤互联隐私政策》列明的方式申请。

四、设备连接、激活与控制

1. 使用蓝牙设备功能时，应用需要调用蓝牙/附近设备能力；部分Android版本可能同时要求位置相关权限。扫码连接4G设备需要相机或系统扫码能力，保存图片和截图可能需要相册/媒体权限。您可以拒绝或在系统设置中撤回权限，但对应功能将无法使用。

2. 您确认对所连接、绑定、激活或控制的设备具有合法所有权、管理权或使用授权。不得连接来源不明的设备，不得绕过访问控制，也不得利用本服务控制无权操作的设备。

3. 蓝牙、4G、网络、设备固件、系统版本、电量、距离、信号强度和硬件状态均可能影响连接和指令执行。应用页面显示“已发送”或“连接成功”不代表设备在所有情况下均已完成预期物理动作，您应结合设备屏幕、指示灯、现场状态和操作说明进行确认。

4. 设备激活码、管理员密码、启动密码和授权信息具有安全属性。您应妥善保管，不得向无关人员披露。因泄露或误用导致设备被未经授权访问的，责任由过错方依法承担。

5. 熔接、加热、红光、OTDR测试、固件升级、恢复出厂设置、校准和其他设备操作具有专业性。您应遵守设备说明和现场安全规范，在确认设备、人员和光路安全后操作。具有不可逆结果的操作，应在执行前再次核对。

3. 应用提供的删除、清空、恢复出厂设置、解绑和固件更新等操作可能无法撤销。请在操作前确认目标设备和数据，并自行备份需要保留的内容。

4. 您导出、保存、分享或向第三方发送设备记录和图片时，应确保拥有合法权利并采取必要的脱敏和安全措施。不得利用本服务传播违法内容或侵害他人权益。
