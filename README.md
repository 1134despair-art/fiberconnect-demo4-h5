# 光纤互联 H5 原型

Vue 3 + Vite 的移动端原型，包含首页、产品、设置、注册登录和八类设备页面。保留前端模拟数据与 LocalStorage 流程；真实设备通信、短信、后台授权等接口仍待接入，不作为真实设备联调版本。

## 安装与运行

要求 Node.js >= 20.17.0，使用与 Node 版本匹配的 npm。当前使用 Vite 6，依赖以 package-lock.json 为准。

```sh
npm install
npm run dev
```

默认开发地址为 http://127.0.0.1:8081/，端口占用时请指定空闲端口。`.puppeteerrc.cjs` 默认跳过测试浏览器下载，不影响 H5 构建。

## 发布到原型广场

本仓库发布分支为 `master`。在仓库根目录执行：

```sh
npm install
npm run build:prod
```

构建先执行 Vue / TypeScript 检查，再生成 `dist/index.html` 和 `dist/assets/`。发布时使用完整 dist 目录。源码入口为 `src/index.html`，Vite 使用 `base: './'`，路由采用 Hash 模式，支持 `/prototype-preview/{projectCode}/{demoCode}/#/` 多级目录。

提交源码及完整本地资源，依赖目录、构建产物、凭证、截图、缓存及旧部署包不进入 Git。GitLab 推送后由平台既有 Webhook / Jenkins 配置触发构建；推送成功不等同于平台发布成功。

仓库保留原有 GitHub Pages 工作流配置，仅在 GitHub 上生效。域名根目录 ruanyi.top 留作个人网站，不在此部署 App。

## 2026-10-10 交付内容

- 统一首页、产品、设置、注册登录、操作手册及设备页面的布局与交互。
- 智能 OTDR 竖屏测量与事件地图、可横向滚动结果表格、设备激活及授权原型流程。
- 四类三期设备页面与弹窗调整、售后订单持久化、产品详情补全。
- 账户与设备数据隔离、测量结果和文件读写、头像同步及导出流程修复。
- 图标全部本地化，移除在线 Iconify 加载脚本；原始 SVG、来源、许可和文件清单在 `src/assets/icons/`，开发接入见该目录 README.md。

产品照片、部分产品详情与文档媒体仍可能使用已上架系统的远程地址。页面样式保留原有 Tailwind CDN；本次图标本地化不代表整个 App 已完全离线化。默认头像使用本地文件。

## 接口与验证范围

原型的登录、找回密码、激活和授权演示不能替代正式服务端鉴权。已完成的页面与交互回归记录不等同于真机及真实设备验收。正式上线前仍需对设备协议、后台接口、不同系统的下载和分享做联调。
